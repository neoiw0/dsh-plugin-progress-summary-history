# 知乎文案：给朋友的 DSH 插件安装指引

> 两个插件配套使用：
> **① `dsh-progress-summary`** —— 在输入框上方显示一行"当前在干什么"的播报。**作者：tastynoob**（GitHub，MIT 许可），不是我的作品；
> **② `dsh-plugin-progress-summary-history`** —— 把每一行播报累积成右侧「进度历史」面板，**点一下播报行就能打开**。**作者：neoiw0**（我写的，MIT 许可）。

---

## 正文（可直接发）

最近在 DeepSeek Harness（DSH 桌面版）上折腾出两个配套的小插件，装上之后等结果的时候不用再盯着屏幕猜"它到底在干嘛"。

先说清楚分工：**播报行**那个（`dsh-progress-summary`）是 **tastynoob** 写的，MIT 许可，我只是使用者；我写的是**历史面板**（`dsh-plugin-progress-summary-history`），它把 tastynoob 那个插件的播报攒成可回看的时间线，并接管了"点播报行"这个动作。

**它长什么样**：输入框上方会出现一行中文播报，比如"正在核对配置与日志，确认后恢复专用模型并验证输出"；右侧边栏多一个「进度历史」页签，把历次播报按时间排好，最新的在最下面，越往上越旧。**点一下那行播报，历史面板就打开了**。

**安装（用界面装，不要用命令行）**

桌面版**没有** `dsh` 命令，插件要走界面装：

1. 打开 DSH → 左侧「**插件**」→ 右上角「**+ 添加插件**」
2. 在「包名或地址」里粘**第一条地址** → 安装 → **重启 DSH**
3. 再重复一次，粘**第二条地址** → 安装 → **重启 DSH**

```
① 播报行（作者 tastynoob，MIT）
git+https://github.com/tastynoob/dsh-progress-summary.git

② 历史面板（作者 neoiw0，MIT）
https://github.com/neoiw0/dsh-plugin-progress-summary-history/releases/download/v0.1.5/dsh-plugin-progress-summary-history-0.1.5.tgz
```

（两条都实测过：`pnpm add` 装第一条 9.3 秒、第二条 9.7 秒。如果你那边连 GitHub 超时，先挂代理，或者到 Release 页手动下载 tgz，再用「添加插件 → 本地文件」安装。）

**每装一个插件都要重启一次 DSH**（配置和插件都不热更新）。

**关于播报用哪个模型（重要，别踩坑）**

播报只要一个小模型，一次几十个字。但**免费档是限时的，随时可能下线**——我写这篇时前后已经死过两个：

- `minimax-m3.1-flash-free` → 已 `410` 下线
- `longcat-2.5-preview-free` → 昨天还能用，今天也 `410` 下线了
- `beam-free` → `403` 锁区；`iceman-contributor-free` → `503` 上游挂了
- OpenCode **Zen** 免费档用 `public` 当密钥、确实不要账号，但只允许 OpenCode 官方客户端调用，第三方（DSH）会 `403`

所以装好之后**先用探测器确认当前有没有能用的免费模型**：

```bash
npm run probe:free
```

有可用模型时它会直接列出来（脚本会告诉你填哪个 model）。另外两个必须注意的点：

1. 网关现在**强制要求 `x-opencode-session` 请求头**，缺了直接 `400`——provider 块里要写 `headers`。
2. API Key 在 **DSH 设置里点「Add API Key」** 填（存到 `~/.dsh/.credentials.yaml`，名字 `OPENCODE_GO_API_KEY`），不是系统环境变量。

配置片段（`~/.dsh/profiles/desktop/cordis.patch.yml`，改完必须重启 DSH）：

```yaml
# providers 下：
      opencode-go-free:
        displayName: 播报专用（OpenCode Go）
        api: openai-completions
        baseURL: https://opencode.ai/zen/go/v1
        apiKeyEnv: OPENCODE_GO_API_KEY
        headers:
          x-opencode-session: 任意本地标识
        models:
          - id: <探测器列出的可用模型>
            name: 播报用
            contextWindow: 1000000

# 文件末尾：
- id: progress-summary
  name: 'dsh-progress-summary'
  config:
    provider: opencode-go-free
    model: <同上>
    effort: 'off'
    lang: zh
    maxTokens: 256
    excerptChars: 300
    timeoutMs: 25000
    minIntervalMs: 45000
    minTokens: 200
```

**两个小提示**

1. 历史面板依赖播报插件——只装②不装①，面板会一直是"暂无进度"。
2. 播报行**只在 agent 干活时出现**，空闲时按设计隐藏，不是坏了。

**两个仓库都在 GitHub，都是 MIT 许可：**

- 播报行（tastynoob）：https://github.com/tastynoob/dsh-progress-summary
- 历史面板（neoiw0）：https://github.com/neoiw0/dsh-plugin-progress-summary-history
（历史面板里带 `npm run doctor` 体检、`npm run config:fix` 一键补配置、`npm run verify:narrator` 查播报链路，遇到问题先跑这三个。）
