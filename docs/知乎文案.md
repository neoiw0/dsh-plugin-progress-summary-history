# 知乎文案：给朋友的 DSH 插件安装指引

> 两个插件配套使用：
> **① `dsh-progress-summary`** —— 在输入框上方显示一行"当前在干什么"的播报。**作者：tastynoob**（GitHub，MIT 许可），不是我的作品；
> **② `dsh-plugin-progress-summary-history`** —— 把每一行播报累积成右侧「进度历史」面板，**点一下播报行就能打开**。**作者：neoiw0**（我写的，MIT 许可）。

---

## 正文（可直接发）

最近在 DeepSeek Harness（DSH 桌面版）上折腾出两个配套的小插件，装上之后等结果的时候不用再盯着屏幕猜"它到底在干嘛"。

先说清楚分工：**播报行**那个（`dsh-progress-summary`）是 **tastynoob** 写的，MIT 许可，我只是使用者；我写的是**历史面板**（`dsh-plugin-progress-summary-history`），它把 tastynoob 那个插件的播报攒成可回看的时间线，并接管了"点播报行"这个动作。

**它长什么样**：输入框上方会出现一行中文播报，比如"正在核对配置与日志，确认后恢复专用模型并验证输出"；右侧边栏多一个「进度历史」页签，把历次播报按时间排好，最新的在最下面，越往上越旧。**点一下那行播报，历史面板就打开了**。

**安装（两条命令）**

```bash
# ① 播报行 —— 作者 tastynoob（MIT），GitHub 直装
dsh plugin --profile desktop add "git+https://github.com/tastynoob/dsh-progress-summary.git"

# ② 历史面板 —— 作者 neoiw0（MIT），从 Release 装
dsh plugin --profile desktop add "https://github.com/neoiw0/dsh-plugin-progress-summary-history/releases/download/v0.1.4/dsh-plugin-progress-summary-history-0.1.4.tgz"
```

装完重启一次 DSH。

**关于播报用哪个模型（重要，别踩坑）**

播报只需要一个便宜的小模型，一次几十个字。实测结论：

- OpenCode **Go** 网关上有免费档，目前能用的是 **`longcat-2.5-preview-free`**（价格 0/0，1M 上下文，一次约 5 秒出文）。它需要 OpenCode 账号的 **API Key**（注册免费），填在 `OPENCODE_GO_API_KEY` 环境变量里。
- OpenCode **Zen** 那套免费档虽然用 `public` 当密钥、不用账号，但**只允许 OpenCode 官方客户端调用**，第三方（DSH）请求会直接 `403 FreeTierError`——不用浪费时间试。
- 免费模型有**突发限流**（约每 15 秒 3 次），超了返回 `429`，表现是"播报行突然不出现了"。所以把播报间隔设成 45 秒最稳。

在 `~/.dsh/profiles/desktop/cordis.patch.yml` 里加这段（`- id: llm-pi-ai` 的 `providers` 下加 provider，文件末尾加插件配置）：

```yaml
# providers 下：
      opencode-go-free:
        displayName: 播报专用（OpenCode Go 免费档）
        api: openai-completions
        baseURL: https://opencode.ai/zen/go/v1
        apiKeyEnv: OPENCODE_GO_API_KEY
        models:
          - id: longcat-2.5-preview-free
            name: LongCat 2.5 Preview（免费）
            contextWindow: 1000000

# 文件末尾：
- id: progress-summary
  name: 'dsh-progress-summary'
  config:
    provider: opencode-go-free
    model: longcat-2.5-preview-free
    effort: 'off'
    lang: zh
    maxTokens: 256
    excerptChars: 300
    timeoutMs: 25000
    minIntervalMs: 45000
    minTokens: 200
```

**两个小提示**

1. 历史面板依赖播报插件——只装②不装①，面板会一直是"暂无进度"。
2. 播报行**只在 agent 干活时出现**，空闲时按设计隐藏，不是坏了。

**两个仓库都在 GitHub，都是 MIT 许可：**

- 播报行（tastynoob）：https://github.com/tastynoob/dsh-progress-summary
- 历史面板（neoiw0）：https://github.com/neoiw0/dsh-plugin-progress-summary-history
（历史面板里带 `npm run doctor` 体检、`npm run config:fix` 一键补配置、`npm run verify:narrator` 查播报链路，遇到问题先跑这三个。）
